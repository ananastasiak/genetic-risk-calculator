# Genetic Risk Calculator

Программа для расчёта баллов генетического риска,
определения уровней риска и формирования заключений
на основе данных из Excel-файла.

Данные учебные, результаты не предназначены
для клинической интерпретации.

## Установка и запуск

Программа протестирована на Python 3.14.9.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.main
```

По умолчанию используется файл `data/test_dataset.xlsx`.
Результаты сохраняются в `output/results.csv`.

При необходимости можно указать другие пути:

```bash
python -m src.main --input data/test_dataset.xlsx --output output/results.csv
```

## Алгоритм

Для каждого образца и признака определяются вклады
корректных генотипов и рассчитывается их среднее
арифметическое. Полученный балл ограничивается диапазоном
[-1; 1] и округляется до двух знаков от нуля
(аналог ROUNDUP в Excel).

Уровень риска и заключение определяются по таблице
порогов. Если количество корректных входов меньше
заданного минимума, возвращается «Недостаточно данных».

## Особенности исходных данных

| Проблема или особенность | Решение |
|---|---|
| Конфликтующие вклады APOA5 (A/G): -0.5 и -0.4 | Исключение неоднозначного вклада |
| Недопустимый генотип GPX1 у S02 | Исключение генотипа |
| Диплоидный генотип G6PD у S03 (male) | Исключение генотипа |
| Гемизиготный генотип G6PD у S02 (male) | Сохранение генотипа |
| Обратный порядок аллелей SOD2 у S04 | Нормализация T/C до C/T |
| Значения «ПРОВЕРИТЬ» у S03 и S04 | Исключение генотипов |

## Допущения

- Генотипы рассматриваются как нефазированные,
  порядок аллелей не имеет значения.
- Используется стандартная модель плоидности XX/XY
  для аутосомных и непсевдоаутосомных X-сцепленных локусов.
- Отсутствующие, некорректные и конфликтующие вклады
  не учитываются при расчёте. Нулевые вклады сохраняются.
- Структурные ошибки в справочниках останавливают
  выполнение программы, ошибки отдельных генотипов
  регистрируются как предупреждения.
- Входной файл должен соответствовать структуре
  предоставленного Excel-файла.

## Результаты

Выходной CSV содержит идентификатор образца, код признака,
балл, уровень риска, заключение, количество использованных
вкладов и общее количество вариантов признака.

Для исходного датасета получено 15 результатов,
включая один случай недостаточности данных.

## Тестирование

```bash
python -m pytest -q
```

71 тест успешно пройден. Проверяются загрузка и валидация
данных, обработка генотипов и конфликтующих вкладов,
округление, определение уровней риска и работа программы
на исходном датасете.

## Структура проекта

- `src/data_loader.py` — загрузка и валидация данных.
- `src/calculator.py` — расчёт баллов и уровней риска.
- `src/main.py` — CLI и сохранение результатов.
- `tests/` — автоматические тесты.
- `data/` — исходный датасет.
- `output/` — результаты расчётов.
